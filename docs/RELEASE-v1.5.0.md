# GoodbyeDPI Tray v1.5.0

GoodbyeDPI'ı komut satırıyla uğraşmadan, Windows açılışında sistem tepsisinden kullanmak için küçük bir Windows uygulaması.

![GoodbyeDPI Tray](https://raw.githubusercontent.com/trfurkan/GoodbyeDPI-Tray/main/docs/images/main-dark.png)

## Neler var

- Tek pencereden başlat, durdur, yeniden başlat; yedi Türkiye profili arasında geçiş.
- Sitelerin erişim durumunu, hızını ve DNS çözümlemesini anlık olarak test eden akıllı bir panel; GoodbyeDPI'ın işe yarayıp yaramadığını gösterir.
- GoodbyeDPI başlarken Windows DNS önbelleği temizlenir; engelli siteler motor açılır açılmaz çalışır.
- Motorun gerçek çıktısını gösteren konsol penceresi.
- Windows açılınca otomatik başlama ve sistem tepsisinde bekleme.
- Açık, koyu ve sistem teması.
- Tek dosyalık kurulum. Üstüne kurunca ayarların korunarak güncellenir.

![Erişim testi](https://raw.githubusercontent.com/trfurkan/GoodbyeDPI-Tray/main/docs/images/access-dark.png)

## Bilmen gerekenler

- Kurulum dosyası dijital olarak imzalı değil; Windows SmartScreen uyarı verebilir. **Ek bilgi → Yine de çalıştır** ile devam edebilirsin.
- Hangi profilin işe yarayacağı internet sağlayıcına göre değişir; Erişim testi bunu görmeni kolaylaştırır.
- Windows 11'de test edildi. Windows 10'da ve farklı ekran ölçeklerinde sorun görürsen bildirmen yeterli.
- Profesyonel bir yazılımcı değilim; bu projeyi Codex ve Claude'un yardımıyla yaptım. Bir sorun olursa bildirirseniz çözmeye çalışırım.
