# Site yazı tipleri

Başlıklar ve metinler Manrope, terminal önizlemesi JetBrains Mono kullanır.
Değişken font dosyaları değiştirilmeden alınmıştır ve site üzerinden sunulur.
Ziyaretçinin Google Fonts'a bağlanması gerekmez.

- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
  Lisans: `Manrope-OFL.txt` (SIL Open Font License 1.1)
- JetBrains Mono: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
  Lisans: `JetBrainsMono-OFL.txt` (SIL Open Font License 1.1)

Dosyalar 8 Kasım 2026 tarihinde indirildi. Fontlar projeye özel veya münhasır değildir.
