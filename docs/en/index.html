Technical sources: GoodbyeDPI · WinDivert documentation

A simplified explanation; it does not test or change your real connection. Successful access is not guaranteed on every network.

GoodbyeDPI helps get around some access blocks that internet providers apply by inspecting traffic. With methods such as splitting data into smaller pieces, it makes it harder for the blocking system to recognize the connection. This happens on your computer.

No VPN, no extra server on the way

Your connection does not pass through a VPN server. That way you can get access without the extra latency and speed loss that a distant or busy VPN server can cause. Real speed and access depend on your internet provider, the profile you choose and the site you connect to; zero speed loss is not guaranteed on every connection.

The real tool that tries to get around blocks is GoodbyeDPI. With GoodbyeDPI Tray we make it more capable and practical: starting it, choosing profiles and DNS, taking breaks and testing connections are all in one window, without making it complicated.

What it does and doesn't do

Click a card you're curious about to see the difference.

DOESHelps get around some access blocks

Against DPI-based blocks it uses methods that make your traffic harder to recognize. The result depends on your internet provider and the profile you choose.

DOESHandles your connection on your own device

Your traffic is not routed to a VPN server. You can manage profile, DNS and site list settings from the app.

DOESN'THide or change your IP address

It is not a VPN or an anonymity tool. Sites still see your real connection's public IP address; it does not create an extra encrypted tunnel.

DOESN'TGuarantee access past every block or a steady speed

It cannot get around direct IP blocks. Network conditions, the method used and the target site can affect both access and performance.

FAQ

Is GoodbyeDPI Tray a VPN?

No. It does not route your traffic through a VPN server and does not change your IP address. It uses the GoodbyeDPI engine to help get around some access blocks; it does not provide a VPN's privacy features.

Does it work for Discord?

You can try it to reach Discord. The result depends on your internet provider, the block in place and the profile you choose. Start with Arx, then check the result on your own connection with the access test.

Which profile should I choose?

The recommended Arx profile is a good start. If it doesn't work, compare the options with Find a suitable profile. The DNS provider you pick is only used by profiles that redirect DNS.

Why does Windows show a warning?

The installer has no publisher signature that Windows recognizes, so you may see a SmartScreen warning. The warning alone does not mean the app is harmful. Download the installer only from this project's GitHub releases and read the warning's details. Don't run files whose source you aren't sure of.

Why do Chrome, Edge or Firefox warn while downloading?

Newly published, rarely downloaded or unsigned installers can trigger browser warnings. Using open-source components does not remove these warnings automatically. Make sure you downloaded the file from this project's GitHub releases and check why the warning appears; don't treat every warning the same and click past it.

Is the app trustworthy?

GoodbyeDPI Tray is built on open-source projects such as GoodbyeDPI and WinDivert. It aims for safe and transparent use; its source code is on GitHub. There is no guarantee of full security or trouble-free operation; you use it at your own responsibility.

What if I already installed GoodbyeDPI-Turkey?

If the installer finds an existing GoodbyeDPI service, it asks before taking it over. When you agree, your supported profile is kept. Check that the new installation works before deleting the old folder.

How do I uninstall it?

Use the uninstall option in the app or Windows Settings → Apps. The installer removes your settings and logs along with the app.
