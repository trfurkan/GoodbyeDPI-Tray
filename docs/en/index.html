Use GoodbyeDPI in one click

GoodbyeDPI Tray is a Windows app that lets you reach Discord and blocked sites without a VPN.

Download for free Source code

Windows 10 / 11 · Free and open source · Release notes

What does it do?

Internet providers in Turkey block some sites through DPI and DNS. GoodbyeDPI gets around these blocks right on your computer, and GoodbyeDPI Tray makes it easy to manage.

Not a VPN

No. Traffic is not routed through another server and your IP address stays the same. Connection results and speed depend on your provider, the site and the selected profile.

Choose the scope

Enable listed-sites-only mode and edit the site list to choose where changes apply.

It has limits

It cannot bypass direct IP blocks. Access tests show connection results, not definitive proof of why a connection failed.

Features

It uses the settings from GoodbyeDPI-Turkey and adds an interface you'll actually enjoy using every day.

One-click controls

Start, stop, switch profiles or take a short break. Manage the app from the tray icon too.

Choose your DNS

Unfiltered AdGuard is the default. Yandex, ad-blocking AdGuard, Quad9, OpenDNS and CleanBrowsing are also available. Profiles that do not use DNS disable this selector.

Editable site list

Apply changes only to listed sites. Add or remove addresses in the Sites screen.

Quick and detailed tests

Quick checks for Discord, Roblox and Wattpad; a 10-site detailed test expands inside the same card.

Find a suitable profile

Compare seven profiles. Start with the recommended Arx profile and choose what works for your connection.

Console and issue reports

Read live engine output inside the main window. Report a problem opens a GitHub issue draft.

Seven themes, three languages

Light, Dark and five colour themes; Turkish, English and Russian. The theme can also follow Windows.

Start with Windows

Control automatic startup and the tray icon from Settings.

Themes and languages

Besides Light and Dark there are five colour themes. You can switch the language to Turkish, English or Russian from the flag next to the theme button.

Does it work? See for yourself

The quick test checks Discord, Roblox and Wattpad. The detailed test expands inside the same card and shows HTTPS results and timings for 10 sites. A failed connection alone does not prove blocking: DNS, a timeout or the site itself may be responsible. When list mode is enabled, only listed sites are affected.

Install

One file, takes about a minute. Needs Windows 10/11 and .NET Framework 4.8, which Windows usually already has.

Download the installer
  1. Open the installerIf Windows SmartScreen warns you, choose More info → Run anyway.
  2. Press InstallRead the note, tick the box and approve Windows' permission prompt.
  3. StartOpen the app and press Start. The app takes care of the rest.
  4. Run the Access testIf sites don't open, pick another profile.

FAQ

Is GoodbyeDPI Tray a VPN?

No. Traffic is not routed through another server and your IP address stays the same. Connection results and speed depend on your provider, the site and the selected profile.

Does it work for Discord?

Discord is blocked through DPI and DNS, so it works with most providers in Turkey. Which profile works depends on your provider; the app's Access test makes that easy to see.

Which profile should I pick?

Start with the recommended Arx profile. If it does not work, use Find a suitable profile to compare alternatives. DNS selection only affects profiles that use DNS.

Why does Windows show a warning?

The installer isn't digitally signed, so Windows SmartScreen may warn you. Choose More info → Run anyway to continue. All of the app's source code is open on GitHub.

Why do Chrome, Edge or Firefox warn me when downloading?

Browsers show warnings like "not commonly downloaded" or "may be harmful" for unsigned files that few people have downloaded yet. That means they don't recognise the file yet, not that they found a problem. In Chrome and Edge choose Keep from the menu next to the file in the downloads list; in Firefox choose Allow download. Always download the installer only from this page or the GitHub Releases page.

Can I trust the app?

The source code is open on GitHub. Update checks connect to GitHub; access tests connect to the selected sites. Report a problem opens an issue draft that you can review before submitting. The app is experimental and may not work on every network.

What if I already installed GoodbyeDPI-Turkey?

The installer finds the old GoodbyeDPI service and asks before taking it over. If you agree, your profile is kept and you can delete the old folder afterwards.

How do I uninstall it?

Press Uninstall in the app or remove it from Windows Settings > Apps. The app is removed completely, including its settings and logs.
