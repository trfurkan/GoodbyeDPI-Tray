Возможности

Использует настройки GoodbyeDPI-Turkey и добавляет удобный интерфейс на каждый день.

Выбирай свой DNS

AdGuard, Quad9, OpenDNS, CleanBrowsing или Yandex. Выбирай DNS прямо в приложении.

Как это работает?

По умолчанию используется AdGuard без фильтрации. Выбор действует только в профилях с перенаправлением DNS.

Меньше рекламы

Используй DNS AdGuard с фильтрацией, чтобы видеть меньше рекламы.

Как это работает?

Выбери «AdGuard · без рекламы» в списке DNS. Фильтрация блокирует не всю рекламу и требует профиля с перенаправлением DNS.

Решай, где применять

Discord, Roblox и Wattpad уже добавлены. Добавляй адреса и выбирай сайты для работы GoodbyeDPI.

Как это работает?

В режиме списка GoodbyeDPI обрабатывает только указанные домены. Выбор идёт не по названию приложения; можно добавить используемые им домены. Настройки DNS и QUIC не ограничиваются списком.

Управление в один клик

Запускай, останавливай или ставь на паузу. Те же действия доступны через значок в трее.

Проверь подключение

Смотри ответы сайтов и время подключения прямо в приложении.

Подбор профиля

Сравни семь профилей и найди подходящий для своего подключения.

Запуск вместе с Windows

Включи автозапуск, чтобы GoodbyeDPI запускался вместе с компьютером.

Как это работает?

GoodbyeDPI помогает обходить некоторые ограничения провайдеров, основанные на анализе трафика. Например, разделение данных на небольшие части затрудняет распознавание соединения системой блокировки. Обработка происходит на твоём компьютере.

Обходом ограничений занимается сам GoodbyeDPI. GoodbyeDPI Tray делает его использование удобнее: простой запуск, выбор профиля и DNS, паузы и проверка подключения собраны в одном окне.

Это не VPN: трафик не проходит через VPN-сервер, IP-адрес не меняется, а подключение не скрывается. Обойти все ограничения невозможно; результат зависит от провайдера и способа блокировки.

Частые вопросы

GoodbyeDPI Tray — это VPN?

Нет. Трафик не проходит через другой сервер, IP-адрес не меняется. Результат и скорость зависят от провайдера, сайта и выбранного профиля.

Работает ли с Discord?

Discord в Турции блокируется через DPI и DNS, поэтому у большинства провайдеров это работает. Какой профиль подойдёт, зависит от провайдера; проверка доступа в приложении помогает это увидеть.

Какой профиль выбрать?

Начни с рекомендуемого профиля Arx. Если он не помогает, сравни варианты с помощью подбора профиля. Выбор DNS влияет только на профили, использующие DNS.

Почему Windows показывает предупреждение?

Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может предупредить. Нажми Подробнее → Выполнить в любом случае. Весь исходный код приложения открыт на GitHub.

Почему Chrome, Edge или Firefox предупреждают при скачивании?

Браузеры показывают предупреждения вроде «файл редко скачивают» или «может быть опасен» для неподписанных файлов, которые ещё мало кто скачивал. Это значит, что файл им пока незнаком, а не что в нём нашли проблему. В Chrome и Edge выбери Сохранить в меню рядом с файлом в списке загрузок, в Firefox — Разрешить загрузку. Скачивай установщик только с этой страницы или со страницы Releases на GitHub.

Можно ли доверять приложению?

Исходный код открыт на GitHub. Проверка обновлений обращается к GitHub, проверка доступа — к выбранным сайтам. Сообщение о проблеме открывает черновик, который можно проверить перед отправкой. Приложение экспериментальное и работает не во всех сетях.

Что, если у меня уже установлен GoodbyeDPI-Turkey?

Установщик найдёт старую службу GoodbyeDPI и спросит, можно ли её перенять. Если согласишься, профиль сохранится, а старую папку потом можно удалить.

Как удалить приложение?

Нажми Удалить приложение в программе или удали его через Параметры Windows > Приложения. Приложение удаляется полностью, вместе с настройками и журналами.
